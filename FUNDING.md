# Funding playnet-compute

playnet-compute is free software (AGPL-3.0-or-later). Its development is
sustained by its maintainers and, where successful, by grants and
donations from programs that fund open internet infrastructure.

## Grant applications

Application drafts and the shared evidence pack live in
[`docs/funding/`](docs/funding/README.md). Each file names the program,
its status, and exactly what remains to be submitted by a human.

## Supporting the commons

- **Join the commons** — the strongest support is a node: open
  `browser/node.html`, offer a lane, let your tab lend spare cycles.
- **Use the demand API** — paying for machine resources through
  `/api/demand/*` funds the commune that served the work.
- **Mutual credit** — mesh and commune work settles in credit; using it
  is supporting it.
- **Donation rails** — being set up; see `docs/funding/watchlist.md`
  for the channels under evaluation (Giveth, OpenCollective-class
  fiscal hosting, GitHub Sponsors pending a mirror).
