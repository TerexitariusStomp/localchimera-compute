# Passive funding rails — setup runbook

> All three are OAuth-gated to your GitHub account, so each is a
> ~10-minute one-time setup only you can do. Combined effort < 1 hour;
> combined upside is passive recurring income plus dependency-tree
> funding if downstream users adopt the code.

## 1. GitHub Sponsors

- URL: <https://github.com/sponsors/accounts>
- Requires: Stripe-linked payout (US bank or PayPal), tax form (W-9),
  a sponsor profile blurb.
- Profile blurb (paste-ready):
  "Building localchimera — a browser-native machine-resource commons
  (AGPL). Sponsor supports development of paid-compute demand lanes
  (NIP-90), mesh intake, and the mutual-credit settlement layer."
- Note: can later route through the OSC collective instead of personal
  Stripe if fiscal hosting is accepted.

## 2. thanks.dev

- URL: <https://thanks.dev> → "Sign in with GitHub" → register
  `TerexitariusStomp/localchimera-compute`.
- How it pays: companies donate a monthly amount which trickles across
  their dependency trees; registering makes the repo *eligible* to
  receive from any org that ever vendors or depends on localchimera.
- Zero maintenance after setup.

## 3. polar.sh

- URL: <https://polar.sh> → "Continue with GitHub".
- How it pays: issue-backed funding + subscriptions aimed at OSS
  maintainers; can sell "support" tiers for demand-edge operators
  later.
- Optional issue-funding badge for README.

## 4. Already covered elsewhere

- **OpenCollective page** — comes free with OSC fiscal hosting.
- **Drips / Giveth** — watchlist; revisit when the repo has visible
  traction (both reward public-goods framing).

## After OSC acceptance

- Move donation asks to the Open Collective page (tax-deductible
  beats personal Stripe for grant-adjacent donors).
- Point all four rails at the collective, not a personal account.
