Geo-distributed fleet — the plan

Companion to fleet-geo-distribution-plan.md. The provider tables above are inputs; this section is the plan: how many servers, what size, in which jurisdictions, with the KERI witness layer, and the optimal fleet that satisfies every constraint at least cost. The lever is decomposition: the planner solves scope by scope, coupled only by pulls on shared goods (ADMM, ~30 rounds, scope-count-independent), so per-node RAM ≈ (target nnz ÷ scopes) × 250 B — a finely-resolved world (10¹⁰ nnz) over 40 scopes is ~64 GB/node, not a 2.5 TB monolith. Pull-coupling is small and latency-tolerant, so nodes sit on different continents for free.

Jurisdiction & data-regulation matrix

Two risks are distinct. Confidentiality is handled in hardware: SEV-SNP keeps plan memory encrypted and attested, so a seized plan-node yields ciphertext, not data. What survives is availability — a seizure/compulsion can halt a node — so the levers are jurisdiction diversity, redundancy, and a witness threshold no single legal bloc can reach.

Two hard rules.  (a) Confidential compute on every node — SEV-SNP, or an equivalent (Intel TDX; owned bare-metal where you control the kernel) — applied to all roles, witnesses and coordinators included; this excludes any plaintext-memory host (SporeStack-VPS, ExtraVM, Cloudzy) from the fleet entirely.  (b) No Five-Eyes jurisdiction (US · UK · CA · AU · NZ) — excluded outright, even for availability-only roles, because intel-sharing makes a single compulsion effectively five.

KERI witness set — a quorum no single bloc can seize

Each federation AID publishes its key events to N witnesses; an event is accountable once toad of them receipt it. Witnesses hold public key-event logs (not plan data), so they are tiny (~1–2 GB) and could in principle run anywhere — but rule (a) puts them on SEV-SNP nodes too (one node profile to attest, defence in depth). The design constraint is seizure: pick N, toad, and placement so the largest witness set under any one cooperating bloc is < toad — then no bloc can either censor (block reaching toad) or fork (gather a competing toad) the key state.

Chosen: N = 6, toad = 4 (majority of 6 ⇒ no fork; tolerates 2 down). With Five-Eyes excluded the supply is EU-heavy, so balance 2 per bloc — EU/EEA · neutral CH · non-aligned SG — leaning on owned SNP colo to fill the second CH and SG slots. Then a full seizure of any one bloc (2) still leaves 4 = toad ⇒ key-event continuity holds, and every witness is SNP.
